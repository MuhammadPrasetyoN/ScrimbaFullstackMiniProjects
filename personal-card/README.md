# Personal Card

Mini project ini adalah kartu profil sederhana yang dibuat dengan HTML dan CSS. Fokus utamanya adalah menampilkan identitas singkat dalam layout yang bersih, rapi, dan mudah dibaca.

## Preview

Halaman menampilkan:

- foto profil berbentuk bulat
- nama
- profesi
- lokasi
- efek hover dan animasi ringan pada card

## Teknologi

- HTML5
- CSS3

## Struktur Folder

```
.
├── index.html
├── styles.css
└── images/
```

## Cara Menjalankan

1. Buka folder project ini di VS Code atau text editor favorit kamu.
2. Jalankan `index.html` langsung di browser, atau pakai extension seperti Live Server.
3. Edit isi teks, gambar, dan styling sesuai identitas yang kamu mau.

## Yang Bisa Dikustomisasi

- nama dan job title di `index.html`
- foto profil di folder `images/`
- warna card, font, shadow, dan animasi di `styles.css`

## Catatan

Project ini dibuat sebagai latihan mini project frontend, jadi tidak membutuhkan instalasi dependency tambahan.
