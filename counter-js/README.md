# Counter App

Project sederhana untuk menghitung jumlah orang yang masuk, mengurangi hitungan, lalu menyimpan hasil ke riwayat.

## Fitur

- Menambah angka dengan tombol `INCREMENT`
- Mengurangi angka dengan tombol `DECREMENT`
- Menyimpan angka saat ini ke daftar riwayat dengan tombol `SAVE`
- Mereset hitungan setelah disimpan

## Cara Menjalankan

1. Buka folder `counter-js`
2. Jalankan project dengan Live Server atau server lokal pilihan kamu
3. Buka `index.html` di browser

## Struktur Singkat

- `index.html` untuk tampilan
- `index.css` untuk styling
- `index.js` untuk logika counter
