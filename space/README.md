# Space Explorer Landing Page

Sebuah landing page modern yang menginspirasi untuk bergabung dengan eksplorasi luar angkasa. Dirancang dengan tema futuristik dan visual yang memukau.

## 📋 Fitur

- **Hero Section** dengan background gallery luar angkasa
- **Responsive Design** yang menyesuaikan dengan berbagai ukuran layar
- **Typography Futuristik** menggunakan font Orbitron dari Google Fonts
- **Call-to-Action Button** untuk mendorong user engagement
- **Footer Section** dengan informasi syarat dan ketentuan

## 🛠️ Teknologi yang Digunakan

- **HTML5** - Struktur markup
- **CSS3** - Styling dengan flexbox layout
- **Google Fonts** - Font Orbitron custom

## 📁 Struktur Proyek

```
space/
├── index.html       # File HTML utama
├── styles.css       # Stylesheet CSS
├── images/          # Folder gambar
│   ├── spacex.png   # Logo SpaceX
│   └── galaxy.webp  # Background galaxy
└── README.md        # Dokumentasi
```

## 🚀 Cara Menggunakan

1. Buka file `index.html` di browser favorit Anda
2. Nikmati visual landing page yang responsif
3. Klik tombol "Apply" untuk action selanjutnya

## 🎨 Warna dan Gaya

- **Warna Utama**: `#82a5ca` (Blue Silver)
- **Warna Accent**: White
- **Font**: Orbitron (400, 800 weight)
- **Tema**: Space & Exploration

## 💡 Highlight

- Background section yang mengisi seluruh viewport dengan sempurna
- Layout yang centered dan terstruktur dengan baik
- Text shadow pada title untuk efek visual yang lebih dramatis
- Smooth transitions dan modern UI elements
